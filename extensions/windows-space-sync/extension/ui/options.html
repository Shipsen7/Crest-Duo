Lokale Spaces funktionieren ohne Apple-Anmeldung. Für CloudKit brauchst du einen Web-API-Token des Fennavio-Containers und die passende Callback-Konfiguration. Production bleibt in dieser Preview schreibgeschützt.

Nur CrestReview-…-Zonen. Zuerst mit künstlichen Testdaten auf beiden Geräten prüfen. Das Speichern der Konfiguration meldet die lokale Apple-Sitzung ab.

Diese Callback-URL muss beim Web-API-Token hinterlegt sein:

Die Erweiterungs-ID kann sich bei einer Installation in einem anderen Pfad oder Browser ändern. Bei Bedarf die neue URL im Dashboard eintragen. Apple-Passwort ausschließlich im Apple-Anmeldefenster eingeben.

Abmelden verwirft den lokalen Sitzungstoken. Eine bestehende Anmeldung auf Apples Website wird dadurch nicht beendet. Nach einem Browserneustart ist erneut eine Anmeldung erforderlich.
