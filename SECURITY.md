# Security

This is an unreleased native browser development target, not a banking security
certification. Do not include real account data, passwords, cookies, statements
or live banking URLs when reporting a problem. Report sensitive findings through
the repository's private vulnerability reporting channel when enabled; do not
publish exploit details or personal data in a public issue.

Read README.md for release acceptance requirements. Apple supplies the WebKit
engine through OS updates. Fennavio remains responsible for its own navigation,
privacy, persistence, UI and download policies. No custom certificate exception
or silent protection downgrade is permitted.
